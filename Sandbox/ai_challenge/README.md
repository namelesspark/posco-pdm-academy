# AI 챌린지

교안 진도에 맞춰 만든 **번외 연습문제** 모음. 정규 과제나 교안 실습이 아니라
복습·팀 공유용으로 따로 만든 것이라 `Practice/` 가 아니라 여기 `Sandbox/` 에 둔다.

디렉토리 이름이 곧 **커버하는 교안 범위**다.

---

## 목록

| 디렉토리 | 교안 범위 | 다루는 내용 | 형식 |
|---|---|---|---|
| `01_02-04_01/` | 01_02 ~ 04_01 | print·변수·자료형·연산자·입력·문자열·리스트 | `.py` 빈칸 + 풀코딩 |
| `04_02-05_01/` | 04_02 ~ 05_01 | 조건문·for 반복문 (+ 01_02~05_01 종합) | `.ipynb` 셀 단위 |
| `05_02-07_03/` | 05_02 ~ 07_03 | while·리스트 처리·튜플·셋·딕셔너리·함수 | `.py` 풀코딩 10문제 |

---

## 파일 규칙

```
<교안범위>/
├── README.md                    문제 설명 (있는 경우)
├── ai_challenge*.py             문제 (직접 푸는 파일)
└── ai_challenge_answer*.py      정답
```

- 문제 파일과 정답 파일이 **쌍**으로 있다.
- 정답은 전부 실행 검증을 거쳤고, README 의 "예상 출력"은 실제 실행 결과를 그대로 넣은 것이라
  문제를 제대로 풀면 **글자까지 똑같이** 나온다.
- 각 범위는 그 시점까지 배운 문법만으로 풀 수 있게 설계했다.
  아직 안 배운 문법(컴프리헨션·`try`·`import` 등)은 정답에도 쓰지 않았다.

---

## 난이도

교안 실습보다 한 단계 어렵게 잡았다. 주로 이런 걸 노렸다.

- **경계값 함정** — `>` 와 `>=` 를 헷갈리면 틀리도록
- **순서 함정** — `elif` 순서, `continue` 와 인덱스 갱신 순서
- **내장함수 금지** — `max`/`min`/`sum` 대신 반복문으로 직접 구현시키기
- **빈 데이터 방어** — 빈 리스트로 나눗셈이 터지는 지점
- **다단계 조합** — 한 문제 안에서 여러 개념을 엮기

## 푸는 순서

위 표의 순서대로 (`01_02-04_01` → `04_02-05_01` → `05_02-07_03`).
개념이 누적되는 구조라 뒤 범위는 앞 범위 내용을 계속 쓴다.
