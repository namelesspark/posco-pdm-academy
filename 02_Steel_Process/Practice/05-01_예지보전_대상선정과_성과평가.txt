05-01 예지보전 대상 선정과 성과 평가 실습
 ─────────────────────────────────────────────────────────

[실습 목표]
- 설비와 고장 유형별로 적절한 보전 전략을 선택한다.
- 재현율과 정밀도를 계산하고 의미를 해석한다.
- 리드타임을 고려해 모델의 실제 현장 활용 가능성을 판단한다.


================================================================
문제 1 — 어떤 보전 전략이 적절한가? 
================================================================

철강 공장에서 다음 세 가지 고장 유형을 검토하고 있습니다.

A. 열풍 송풍기 베어링 열화
- 고장 영향 : 큼
- 고장 빈도 : 연 4회
- 고장 전 전조 : 진동이 점진적으로 증가
- 현재 데이터 : 진동 1분 주기, 고장 이력 있음
- 대응시간 필요 : 10일

B. 원료 컨베이어 이물 끼임
- 고장 영향 : 큼
- 고장 빈도 : 연 2회
- 고장 전 전조 : 직전까지 특별한 변화 없음
- 현재 데이터 : 전류·속도 데이터 있음
- 대응시간 필요 : 1일

C. 예비 냉각수 펌프 씰 열화
- 고장 영향 : 작음
- 고장 빈도 : 연 1회
- 고장 전 전조 : 압력 저하가 나타남
- 현재 데이터 : 압력 데이터 있음
- 대응시간 필요 : 2일


각 대상에 가장 적절하다고 생각하는 보전 전략을 하나 고르세요.

선택지
- BM  : 사후보전
- TBM : 시간기준보전
- CBM : 상태기준보전
- PdM : 예지보전


A. 열풍 송풍기 베어링 열화

선택 :
→ PdM 예지보전______________________________

이유 :
→ 고장 영향도 크고 고장 빈도도 4회로 가장 빈번한데, 진동 주기를 알고 전조 증상도 파악이 가능하니 예측이 가능하다.____________________________________________________

→ 그리고 A 설비는 대응 시간이 다른 설비보다 길기 때문에, 예지 보전 전략이 필요하다.____________________________________________________


B. 원료 컨베이어 이물 끼임

선택 :
→ BM 사후보전______________________________

이유 :
→ 데이터는 있지만 특별한 변화를 볼 수 없지만____________________________________________________

대응 시간이 1일로 비교적 빠르게 설비 복구가 가능하니 사후 보전이 가까운 것 같다____________________________________________________

→ ____________________________________________________


C. 예비 냉각수 펌프 씰 열화

선택 :
→ CBM 상태기준보전______________________________

이유 :
→ 압력 데이터를 통한 압력 저하 상태를 확인할 수 있다.____________________________________________________

→ ____________________________________________________


※ 설비 이름만 보고 고르지 말고,
   고장 영향 · 빈도 · 전조 · 측정 가능성 · 대응 가능성을 함께 보세요.

문제 2 — 모델의 재현율과 정밀도 계산================================================================

A 설비에 예측 모델을 적용했습니다.

지난 1년간 실제 베어링 고장은 10건 발생했습니다.

모델 결과는 다음과 같습니다.

- 실제 고장 10건 중 사전 경보 성공 : 8건
- 놓친 고장                         : 2건

- 전체 경보                         : 20건
- 그중 실제 고장과 연결된 경보      : 8건
- 오탐                              : 12건


[1] 재현율을 계산하세요.

재현율
= 실제 고장 중 사전에 잡아낸 비율

계산 :
→ ___8/10 = 0.8_________________________________________________

답 :
→ __________80______ %


[2] 정밀도를 계산하세요.

정밀도
= 발생한 경보 중 실제 이상이었던 비율

계산 :
→ _____8 / 20_______________________________________________

답 :
→ ______40____________ %


[3] 현장 작업자가 더 직접적으로 체감하는 지표는
    재현율과 정밀도 중 무엇이라고 생각하나요?

선택 :
→ _____정밀도_________________________

이유 :
→ 실제로 울린 경보가 맞는지를 더 직접적으로 체감할 것 같다.____________________________________________________

→ 정밀도가 낮으면 오탐이 많아져 불필요한 점검이 늘어난다.____________________________________________________

    대응시간이 부족한 경보는 몇 건인가요?

    “재현율이 높으므로 현장에 충분히 쓸 수 있다”

문제 4 — 최종 판단================================================================

A. 열풍 송풍기 베어링 열화에 대해 최종 의견을 작성하세요.


[1] 예지보전 적용 대상 자체로는 적절한가요?

[ ] 적절함
[ ] 적절하지 않음
[V] 추가 확인 필요


[2] 현재 모델을 그대로 현장에 적용해도 될까요?

[ ] 가능
[ ] 개선 후 적용
[V] 적용 어려움

[3] 가장 먼저 개선해야 할 항목을 하나 고르세요.

[ ] 더 이른 전조를 잡을 수 있는 신호 추가
[ ] 경보 임계값 조정
[V] 정비 대응 절차 단축
[ ] 고장 사례 추가 확보
[ ] 기타 : ______________________________


[4] 최종 의견을 2~3문장으로 작성하세요.

→ 대응 가능성 부분에서 10일이 필요한데, 최대 10일을 넘지 않는지, 또한 단축이 가능한 지 확인과 개선이 필요한 것 같다.

→ 오탐이 너무 많다. 경보 임계값 조정 등으로 모델을 개선한 뒤 적용하는 것이 적절하다.


─────────────────────────────────────────────────────────
실습 마무리
─────────────────────────────────────────────────────────

이번 실습에서 최종적으로 판단해야 하는 것은
“모델이 고장을 맞혔는가?”만이 아닙니다.

- 이 고장을 굳이 예측해야 하는가?
- 고장 전에 반복 가능한 전조가 있는가?
- 현재 데이터로 그 전조를 볼 수 있는가?
- 모델의 경보가 실제 정비 준비시간보다 충분히 빠른가?
- 경보가 너무 많아 현장에서 감당하기 어려운 수준은 아닌가?

위 질문을 함께 봐야 예지보전 모델의 실제 현장 가치를 판단할 수 있습니다.
