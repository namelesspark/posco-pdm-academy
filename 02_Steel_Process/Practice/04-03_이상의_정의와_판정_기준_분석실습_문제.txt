일자      : 센서 측정한 날짜
진동RMS   : 진동 실효값
부하율    : 진동에 따른 부하율
가동여부  : 가동하고 있었냐 가동 중지하고 있었냐 0과 1로 표시

정상 기준을 만들 때 가동여부가 0인 행을 그대로 포함해도 될까요?

→ _안 된다_

이유 :
→ _0은 가동되지 않은 이상 상태일 수 있는 데이터일 수 있다_

[2] 그래프 1 — 시간에 따른 진동 변화
─────────────────────────────────────────────────────────

Python으로 다음 그래프를 그리세요.

- 가동여부가 1인 행만 사용
- x축 : 일자
- y축 : 진동RMS
- 선 그래프
- 4.5 mm/s 위치에 수평 임계선 추가


[그래프 분석 기록]

초반에는 진동RMS가 대략 어떤 범위와 모양으로 움직이나요?

→ _10일 부근과 22일 부근에서 진동RMS가 값이 급변한다_

어느 구간부터 이전과 다른 지속적인 변화가 보이나요?

→ _100일자 구간부터 지속적으로 진동RMS가 평소 스파이크값보다 높게 올라갔다_

그 변화는 순간적인 스파이크에 가까운가요,
아니면 시간이 지나며 누적되는 추세에 가까운가요?

→ _스파이크 값에 가깝다고 볼 수 있다_

4.5 mm/s 임계치만 사용한다면
실제 변화가 시작된 뒤 얼마나 늦게 반응할 것 같나요?

→ 80일대부터 진동 평균이 올라가기 시작하는데 4.5를 넘는 건 103일이다.
→ _20일 정도 늦게 반응한다_

[3] 그래프 2 — 부하율과 진동RMS의 관계
─────────────────────────────────────────────────────────

80일 미만의 가동 데이터만 사용하여 산점도를 그리세요.

- x축 : 부하율
- y축 : 진동RMS
- 산점도


[그래프 분석 기록]

부하율과 진동RMS 사이에는 어떤 관계가 보이나요?

→ _부하율이 올라가면 진동RMS도 같이 올라간다. 거의 직선에 가깝다 (상관 0.971)_

부하율이 높은 정상 운전에서 진동RMS도 높아질 수 있나요?

→ _높아질 수 있다. 고장이 아니라 부하가 커서 진동이 커진 것일 수 있다_

그렇다면 모든 운전 조건에
4.5 mm/s라는 동일한 임계치를 적용할 때 어떤 문제가 생길까요?

→ _부하가 높은 정상 운전을 이상으로 잡는다. 22일과 58일이 그 경우다 (오탐 2건)_

이 설비에서 진동을 판단할 때
진동값 외에 함께 고려해야 할 조건은 무엇인가요?

→ _부하율. 같은 진동값이어도 부하가 낮을 때 나온 값이 더 위험하다_

[4] 정상 기준 숫자로 확인하기 — Python 사용
─────────────────────────────────────────────────────────

이번 분석에서는 다음 조건을 정상 후보 구간으로 사용합니다.

- 가동여부 == 1
- 일자 < 80

Python으로 아래 값만 확인하세요.

정상 후보 데이터 수  : ___77___ 행
진동RMS 평균          : ___3.306___ mm/s
진동RMS 표준편차      : ___0.452___

통계 임계치 = 평균 + 3 × 표준편차

통계 임계치           : ___4.663___ mm/s


고정 임계치 4.5 mm/s와 통계 임계치를 비교했을 때
어떤 차이가 있나요?

→ _통계 임계치가 4.66으로 고정 4.5보다 높다. 그래서 정상기간 오탐 2건이 사라진다._
→ _대신 최초 검출은 둘 다 103일로 같아서 빨라지지는 않았다_


─────────────────────────────────────────────────────────
[5] 세 가지 판정 결과를 분석하기 — 작성
─────────────────────────────────────────────────────────

분석 결과는 다음과 같습니다.

방식            | 최초 검출일 | 고장 전 확보 시간 | 정상기간 오탐
---------------|------------|------------------|-------------
고정 임계치      | 103일      | 16일             | 2건
통계 임계치      | 103일      | 16일             | 0건
조건 보정 방식   | 84일       | 35일             | 0건


각 방식의 특징을 분석하세요.

고정 임계치
- 장점 :
→ _기준이 하나라 간단하고 설비가 바뀌어도 그대로 쓴다_
- 한계 :
→ _부하가 높은 정상 운전을 이상으로 잡는다. 오탐 2건이 그거다_

통계 임계치
- 장점 :
→ _정상 구간 데이터에서 기준을 뽑으니 오탐이 0건이다_
- 한계 :
→ _정상 구간을 잘못 잡으면 기준이 통째로 틀어진다. 검출 시점은 고정과 똑같아서 빨라지지 않았다_

조건 보정 방식
- 장점 :
→ _부하를 같이 보니 84일에 잡는다. 나머지보다 19일 빠르다_
- 한계 또는 운영 시 확인할 점 :
→ _부하율 데이터가 있어야 쓴다. 부하 센서가 고장나면 같이 무너진다_


왜 조건 보정 방식이 가장 일찍 반응했다고 생각하나요?

→ _진동값만 보면 4.5 아래라 안 걸린다. 근데 부하 대비로 보면 같은 부하에서 진동이 커진 게 먼저 보인다_

→ _80일대부터 부하는 그대로인데 진동만 올라가기 시작했다_

[7] 최종 이상 감시안 작성
─────────────────────────────────────────────────────────

아래 형식에 맞춰 3~5문장으로 정리하세요.

- 이 데이터에서 확인된 가장 중요한 패턴
- 단일 임계치만 사용할 때의 문제
- 추천하는 이상 판정 방식
- 기존 임계치를 계속 유지해야 하는지 여부

[최종 의견]

부하율과 진동RMS의 상관이 0.971이라 진동은 사실상 부하를 따라 움직인다.
그래서 4.5 하나만 쓰면 부하가 높은 정상 운전을 이상으로 잡고(22일, 58일 오탐),
정작 열화가 시작된 80일대는 놓친다.
부하 대비 진동으로 보는 조건 보정 방식을 쓰는 게 맞다. 84일에 잡아서 고장 전 35일을 확보한다.
4.5는 최종 경보로만 남기고 조기 감시는 조건 보정으로 돌리는 게 낫다.
